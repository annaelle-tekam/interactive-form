# interactive-form project
An interactive HTML registration form designed for a bakery community. Built to follow AODA standards and web best practices.
**Note** The user interface is in French (lang="fr").

**Key features**
- **Semantic HTML5:** Built with `<fieldset>`, `<legend>`, and `<label>` elements.
- **Accessibility (AODA):** Linked labels and screen-reader-friendly structure.
- **Interactive Inputs:** Text fields, radio buttons, dropdowns, checkboxes, and file upload.

**Built With**
- HTML5

**Purpose**
Demonstrates front-end structure and web accessibility principles for a Full Stack portfolio.
